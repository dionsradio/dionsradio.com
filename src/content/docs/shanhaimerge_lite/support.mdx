**2. Game Introduction**

*   Shanhai Merge is a relaxing and fun match-3 puzzle game suitable for players of all ages.
*   Match three or more identical tiles to clear the game board and unlock more exciting levels!

**3. Frequently Asked Questions (FAQ)**

*   **Q1: How do I get more coins?**
    *   A: You can earn more coins by completing levels, participating in events, watching ads, etc.
*   **Q2: How do I use power-ups?**
    *   A: Purchase power-ups with coins in the game. Power-ups can help you clear levels more easily.
*   **Q3: What should I do if the game won't start?**
    *   A: Please try restarting the game, checking your network connection, updating the game version, etc.
